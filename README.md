# Ayana: Guardiã das Raízes

Jogo de plataforma criado para o trabalho de Arte (3ª nota, Prof. Tiago), com o tema educação antirracista e temática afro-indígena.

Ayana, filha de mãe quilombola e pai indígena, e o irmão Kauã atravessam o Rio, a Floresta e a Cidade para enfrentar o Senhor Cinza, que apaga as cores e a memória das pessoas.

## Como jogar

- Funciona no navegador do celular ou do computador. No celular, jogue com a tela deitada.
- 1 jogador: ← → andar, Espaço pular, X tocar.
- 2 jogadores: Ayana usa as setas, ↑ e Enter. Kauã usa A, D, W e F.

Feito com a ajuda de uma inteligência artificial (Claude) para a programação.
